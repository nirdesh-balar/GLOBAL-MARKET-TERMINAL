# GMT UI redesign acceptance matrix

These cases are prospective. Existing rc.8 assertions and thresholds remain required. Check the [existing advanced feature tests](ADVANCED_FEATURE_TEST_MATRIX.md) and [test workflow](TESTING.md) for current suites. Use disposable profiles and deterministic provider fixtures. Collect first-pass results separately from any diagnostic retries. A packaged live pass, native window pass and fixture-based CI pass answer different questions.

| ID | Scope | Method and measurable pass criterion |
| --- | --- | --- |
| UI-01 | Layout and resolution | At 1280 × 800 and 1440 × 900, plus high-DPI and a narrow window, visual snapshots show uninterrupted chart area, legible axes and no clipped or inaccessible controls. Check light/dark and 200% zoom. |
| UI-02 | Keyboard and accessibility | Navigate workspace, search, menus, tabs, chart tools and dialogs by keyboard. Verify visible focus, programmatic names, modal trap, Escape order/focus return, and value/status text independent of color. |
| UI-03 | Canonical discovery | Fixture aliases or duplicate names across Yahoo, Hyperliquid spot and perps resolve to separate identities. Search and handoffs retain instrument, interval and market context. Offline and unavailable states explain the issue. |
| UI-04 | Chart transforms and controls | Pan, zoom, fit, reset, percentage scale, timeframe and supported chart types preserve contract, timestamp, scale and visible range. Percentage and absolute selections retain candle/drawing anchors and identify the percentage basis. Provider requests occur only for explicit supported retrieval or refresh. |
| UI-05 | Indicator parity | All 69 existing indicators retain identifiers, deterministic fixture outputs, params, ordering and persistence. Verify EMA 9/20, RSI 14 with 70/30 and Stochastic RSI 14/14/3/3 with 80/20, covering independent instances, shared crosshair/time, pane sizing, settings dismissal and removal. Visibility/settings and local templates, if added, preserve unrelated panes and make zero additional provider requests. |
| UI-06 | Drawing parity | All 86 tools remain reachable; representative placement/editing plus existing suites cover anchors, snapping, locking, hide/remove, undo/redo, selection, restart and invalid-import equality. Poll persisted replacement IDs and exact count before snapshot comparison. |
| UI-07 | Normal Charts warm restore | Existing `terminal-ui.mjs` fixture, one → eight warm, click to rendered frame with all nonempty histories. Strictly <2,000 ms, zero additional provider requests, no renderer errors. Preserve all current assertions. |
| UI-08 | Advanced Chart Grid | Maximum eight active charts and two concurrent new Grid history requests. Verify zero additional provider requests on warm restore, pagination/timeframes/cancellation/maximize/restoration, and stale response rejection. |
| UI-09 | Lifecycle and memory | Switch among Charts/Grid/dock, repeat fixture mounts, teardown and restart. Subscribers, timers, backends and pending jobs return to expected count. Collect timing and peak memory; use the same workload for baseline and candidate. |
| UI-10 | Legacy profile and atomic persistence | Load legacy and malformed or unsupported Grid schema fixtures. Existing watchlists work immediately. Preserve valid settings, drawings/presets/alerts and exports. Verify database integrity, transactions, rollback and restart. |
| UI-11 | Watchlists and scans | Preserve all 59 conditions and scan presets, add/edit/remove watchlist rows, reorder/sections where supported, status, sorting and chart/Grid handoff. Confirm restored row identities and no unintended refresh or stale writes. |
| UI-12 | Alerts | Validate creation, local firing, history and native foreground/background notification through the real existing path. Distinguish unavailable, stale, suppressed and closed-session cases. For a proposed cursor seed, verify canonical ID, timeframe and exact raw price from both absolute and percent modes, then Cancel without creating an alert. |
| UI-13 | Replay and measurement | Fixture bar prefix contains no future values. Step/run/date/exit correctly restore range and issue zero additional provider requests. Measurement time, prices, percentages and session gaps remain accessible. |
| UI-14 | Exports and profile privacy | Existing export formats and scoped destinations preserve drawing/workspace integrity. Verify approved output contents and that fixtures, media, credentials, profiles and raw market data stay out of source and unrelated outputs. |
| UI-15 | Market-wide heatmap, conditional | Verify aggregate return by sample, color legend, comparable sessions, stale/partial labels, token identity and bounded provider requests. Absence of liquidity semantics is visible through metric labels. |
| UI-16 | Public tape/depth, conditional | Provider-qualified crypto fixture exercises timestamp gaps, reconnect, duplicates, partial history, price bucket precision, immutable raw semantics, lifecycle and memory limits. Yahoo and unsupported identities expose accurate unavailability. |
| UI-17 | Actual packaged provider smoke | On disposable Mac ARM64 profile, verify Yahoo non-crypto chart and Hyperliquid spot/perp candle/trade updates and analysis handoffs. Record instrument IDs, timestamp, stream status and errors. Account and order paths must be absent. |
| UI-18 | Native fullscreen and focus | On actual Mac, test Charts and Grid native enter/exit, Escape, event order, pending transition, focus return and renderer errors. Keep existing 15-second test contract and record intermittent failures individually. Native Windows window handling remains pending. |
| UI-19 | Platform and policy gate | Verify blocked unsigned update state and original licensed assets. Source review confirms no new providers, keys, orders/accounts, trading, wallet, login or payment affordances. Preserve Windows x64 setup and pending IDs. |
| UI-20 | Display time-zone and shortcut help, conditional | Search Local/UTC and representative IANA zones. Check DST gap/fold labels, stable candle timestamps and anchors, venue session boundaries and zero provider refetch for display-only changes. Cancel preserves the original zone. Shortcut help matches actual platform bindings, dismissal and return to chart focus. |

Baseline for source CI is 2,431 passed backend tests with one optional skip, 19/19 numerical and 32/32 UI scripts on the hosted complete success.
