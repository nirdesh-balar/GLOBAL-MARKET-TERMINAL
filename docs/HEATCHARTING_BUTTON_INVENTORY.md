# HeatCharting control and interaction inventory

Reference coverage is defined in the [video analysis](HEATCHARTING_VIDEO_ANALYSIS.md). Controls appear as grouped rows when a menu exposes multiple siblings. Status applies per item where a row mixes evidence. **Used** records the visible effect, **Shown** records labels or presentation with unverified activation/results, and **Guide** records described behavior outside verified video interactions. Unreadable control labels are recorded separately. GMT dispositions are proposals in the [feature matrix](HEATCHARTING_FEATURE_MATRIX.md).

## Verification boundary

The guide documents additional shortcuts, replay and analysis behavior. Menu visibility, a tooltip, or a rendered level does not verify an underlying algorithm, a provider claim, a persisted change or an authentication/payment flow. Use the inventory statuses when weighing roadmap claims. [Official guide](https://heatcharting.com/guide)
