# Security

Do not publish credentials, user databases or exploit details in public issues. Prefer GitHub private vulnerability reporting for this repository when enabled. If it is unavailable, contact nirdesh-balar on GitHub first to arrange a private report. No private reporting feature is claimed enabled until verified.

Include affected version/platform, a minimal reproduction on a temporary profile, expected behavior and impact. Remove tokens and personal data from attachments. Signing keys and release credentials belong only in a restricted release environment and never in pull-request CI.

This first v1.0.0 candidate has not completed cross-platform stable or native update acceptance. Do not treat candidate binaries as a supported trusted release. Do not disable Gatekeeper, Defender, code-sign checks or TLS verification to run tests or install an update.
