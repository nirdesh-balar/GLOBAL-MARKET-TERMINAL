# Contributing

Use issues and pull requests at https://github.com/nirdesh-balar/GLOBAL-MARKET-TERMINAL. Discuss financial calculations, data-provider changes and schema migrations before implementation. Keep changes focused and include meaningful tests.

Run the build, relevant Python/numerical/Electron suites and both platform checks when native integration changes. Use unique temporary test profiles. Never open an archived preview or a normal user database in automation. Document the actual host; Mac fixture tests are not Windows acceptance or live-provider evidence.

Preserve canonical instrument identities, read-only routing, financial causality, all chart layouts, 69 studies, 86 drawing tools and 59 screener conditions. Add no broker, wallet, order execution or credential requirements. Never put market data snapshots, personal settings, logs, keys or databases in a contribution.

Pull-request CI receives no signing or release credentials and cannot publish. Maintainers review the exact source revision, tests, license notices and protected release environment before a release. By contributing, confirm you have the right to submit your work under the owner-approved project license. The first MIT license selection is pending owner approval in this candidate.
